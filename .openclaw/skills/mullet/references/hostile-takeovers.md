# When every institution starts sounding like a committee

Choose a business whose failure mode fits the user's input. Borrow the machinery of the business, including at least one unpleasant detail an employee would recognize. The law is only one employer.

| Customer asked for | Someone sold them | Implement the embarrassing part |
|---|---|---|
| Trim whitespace | A coastal retreat program for endangered margins | Survey the two shorelines separately. Offer displaced tabs accommodation at equivalent visual width. Issue a habitat-loss statement for the all-whitespace string. |
| Sort a list | An airline with reserved seating | Give each item a boarding pass, oversell equal keys, grandfather frequent flyers. A stable sort can now be audited by tracing the original seat assignments of two identical passengers. |
| Return HTTP 204 | A museum that lends its empty gallery | Reserve the absence, transport it in a crate, reconcile a tare weight. A tipped crate still weighs precisely nothing. Make Content-Length survive the insurance inquiry. |
| Toggle dark mode | A municipal power cooperative | Tender the sunset in luminance futures. Carry medical exemptions for high-contrast controls. A second click unwinds the hedge and returns the original palette. |
| Add a newline | A railway nationalization | Lease the carriage return from a rolling-stock company. The line feed uses track owned by somebody else. Windows needs both tickets. Preserve a timetable for the last line with no service. |
| Countdown timer | A dairy wholesaler | Sell seconds in cartons with expiry stamps. Pause places remaining cartons in cold storage. Resume inventory from the actual remaining stock. |
| Rename a file | A witness protection program | Issue a new identity, maintain a sealed alias register and relocate dependents. Two witnesses applying for the same name must never overwrite each other. |

Use one conceit long enough to discover something peculiar about the original operation. Write a specimen receipt before implementing it. “Authorization successful” is an error message from your imagination. “Lot 15 may operate an apiary on premises licensed for carbonated beverages” tells you which inputs ought to cause trouble.

If the user asks for a further escalation, acquire a business with incompatible incentives. Let the airline buy the stable-sort algorithm's luggage insurer. Now the insurer can trace each suitcase using the seat assignments that already exist. Adding “FactoryProvider” to all the class names will have to wait until the integration is complete.
