# Form TP-1040EZ (Extended)

Complete only the fields you feel qualified to defend in a deposition. The defaults constitute a duly funded government. Numeric fields are whole numbers. In text fields, name a concrete person, asset, sentence, institution or technology. Use these as design inputs when implementing the requested feature. Each row should change a decision, a transition, a document or the visible result of inspecting a case.
