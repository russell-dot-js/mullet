# mullet

**2 行で済む仕事に、2,000 行分の予算を。**

既定の審議回数は 200 回です。Fizz と Buzz は地番 15 の通行権を争い、タスクを完了するにはチェック欄の X を構成する対角線を二本とも借りなければなりません。

```sh
node examples/fizzbuzz/app.mjs --case 15
python3 examples/todo/app.py add "Milk"
```

## 継続審議

mulletize は各回の実装と動作確認を済ませてから、増えた行数を台帳に記録します。pause で中断し、resume で再開できます。
