# mullet

**두 줄로 끝낼 일을 이천 줄로 청구할 수 있다면?**

기본 예산은 심의 200회입니다. Fizz와 Buzz는 15번 필지의 통행권을 다툽니다. 할 일 하나를 완료하려면 X의 대각선 두 개를 각각 임차해야 합니다.

```sh
node examples/fizzbuzz/app.mjs --case 15
python3 examples/todo/app.py add "Milk"
```

## 무기한 심의

mulletize는 매 회차 실제로 실행되는 코드를 추가하고 동작을 확인한 뒤 증가한 줄 수를 기록합니다. pause로 중단하고 resume으로 재개하세요.
