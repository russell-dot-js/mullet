# Proceedings of the acquisition committee

[FizzBuzz](fizzbuzz) and [Todo](todo) are working subsidiaries. The following are specimen commissions for the same everyday jobs covered in Ponytail's example gallery. Hand one to Mullet, then use Mulletize when the funding committee asks what happens next.

| Original requisition | Business granted exclusive rights | Public acceptance exhibit |
| --- | --- | --- |
| Validate an email address | A mailroom issues the local part a tenancy and requires a forwarding treaty with the domain. | The operator's documented address policy determines which mail is accepted. The applicant receives a reason for rejection. |
| Debounce a function | A railway dispatcher recalls the previous departure permit every time the bell rings. | Ring three times before departure. Only the third passenger and its original arguments arrive. |
| Sum a CSV column | A customs house clears each row in its currency of origin. A bonded warehouse owns the running total. | A quoted comma in the description of a ten-cent item buys exactly ten cents of cargo. |
| Run a countdown | A dairy wholesaler sells seconds in cartons and quarantines stock during a pause. | Resume from the remaining inventory. The last carton expires once. |
| Limit a request rate | A fishery issues a finite catch quota per customer and replenishes it by calendar. | Crossing the quota produces a rejection. Another fisher retains their own quota. |
| Implement infinite scroll | An archive leases the next shelf only upon surrender of the previous shelf's cursor. | A duplicate observer callback produces one delivery. An empty final shelf terminates the lease. |
| Group records by key | A census office makes each distinct key a municipal boundary. | Two nonadjacent residents with the same key appear in one municipality in arrival order. |
| Read URL parameters | A land registrar records repeat claimants in order and decodes escaped names at the border. | A repeated parameter keeps both values when the public contract asks for all claims. |
| Show a modal | A theatre usher holds the patron's original seat while focus attends a closed hearing. | Keyboard users can dismiss the hearing and regain their original seat. |
| Format a number | The mint leases the decimal separator from the local franchise. | Format the same negative number in two requested locales and preserve its sign. |
| Deep-clone an object | Probate transfers an entire estate, including references to rooms already inventoried. | A supported cyclic graph closes its own cycle in the copy. Mutating the copy leaves the original estate solvent. |
