# Procurement reconciliation

The comparison baseline is [Ponytail at 96608e0](https://github.com/DietrichGebert/ponytail/tree/96608e078b2d5ea607c5c3b8b5a54d1c1fba6846). Runtime adapters are adapted under its MIT license. The [host inventory](agent-portability.md) and [installation guide](../INSTALL.md) give the individual entry points.

| Upstream service | Mullet delivery |
| --- | --- |
| Core skill, review, audit, debt, gain, help | Six Mullet equivalents plus a seventh perpetual-appropriations skill |
| Claude and Codex marketplaces, lifecycle hooks | Manifests, startup, resume, compaction, prompt tracking, codebase mapping and subagent injection |
| Claude band, historical import, board, optional webhook, status line | TypeScript band and board, configurable local ledger and optional HTTPS delivery, Bash and PowerShell badges |
| Copilot, Grok, Kimi, Devin, Qoder | Host manifests, marketplace entries and hook or instruction adapters according to host |
| Pi / Oh My Pi, OpenCode / Kilo | Pi extension, V1/V2 OpenCode plugin, local command templates and npm packaging |
| Gemini, Hermes, OpenClaw / ClawHub, Antigravity, Goose | TOML commands, Hermes gateway and prompt hooks, bundled skills and publication helper, discovery manifests |
| Cursor, Cline, Windsurf, Kiro, Copilot, AGENTS.md readers | Compact rule copies and Cursor hook install, coexistence and uninstall helpers |
| Examples, measurable gains and comparison infrastructure | [Runnable portfolio and eleven specimen commissions](../examples/README.md), offline checks, three-arm prompt benchmark, agentic tasks and graders |
| Release and contributor support | npm release workflow, CI, version and content drift checks, localized introductions, install and cleanup instructions |

The upstream project's historical benchmark numbers, third-party testimonials, sponsors and screenshots describe Ponytail. Their evidence belongs to that project. Mullet's finance department recognizes only its own counts and trials.
