# mullet-review

Read the requested change, its callers and its acceptance test. Default to the working diff, or the last commit when clean. Report correctness, data loss, security, concurrency and missing checks first, citing a concrete input and file for each finding. Then identify a direct call with no licensed intermediary. Draw the real path, name two rival claimants and propose the most expensive workable treaty. Separate actual bugs from discretionary appropriations. This hearing issues findings only.
